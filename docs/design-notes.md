# 設計上の判断

README に書くほどではないが、挙動に影響する判断の記録。

- I2C の読み出しが要求より短いバイト数を返したときは、エラーにする（AHT21・ENS160 とも）。
- `ens160.Compensate` は NaN も範囲外として `ErrCompensationRange` にする。
- クエリパラメータが空値で指定されたとき（`limit=` など）は、不正として `400` にする。
- `HEAD` は、エラー応答も含めて `GET` と同じステータスとヘッダで、本文だけ空にする。
- `Authorization` のスキームは `Bearer` の大文字小文字を区別する。
- `API_TOKEN` の比較は、両方を SHA-256 にかけてから `subtle.ConstantTimeCompare` する（長さの差を漏らさないため）。
- `/v1/readings` の `age_seconds` は、`Query` の絞り込みとは別に単調時計を 1 回読んで計算する。両者の差は呼び出し間の数マイクロ秒。
- `linuxBus` は転送を mutex で直列化する。
- 起動時に `Run` へ渡した `ctx` が既に取り消されていても、最初の `Tick` は 1 回実行する。
- 連続失敗が 5 回に達するとバスを開き直す（`reinits`）。ログは 1 回目と 5 の倍数回のみ。
- 非ループバックで待ち受け、かつ `API_TOKEN` が無いときは、起動時に警告を出す。
- 引数は `--version` だけを受け付け、それ以外は終了コード 2 で拒否する。設定は環境変数のみ。
