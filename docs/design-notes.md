# 設計上の判断

README に書くほどではないが、挙動に影響する判断の記録。

- I2C の読み出しが要求より短いバイト数を返したときは、エラーにする（AHT21・ENS160 とも）。
- `ens160.Compensate` は NaN も範囲外として `ErrCompensationRange` にする。
- クエリパラメータが空値で指定されたとき（`limit=` など）は、不正として `400` にする。
- `HEAD` は、エラー応答も含めて `GET` と同じステータスとヘッダで、本文だけ空にする。
- `Authorization` のスキームは `Bearer` の大文字小文字を区別する。
- `API_TOKEN` の比較は、両方を SHA-256 にかけてから `subtle.ConstantTimeCompare` する（長さの差を漏らさないため）。
- `/v1/readings` の `age_seconds` は、`Query` の絞り込みとは別に単調時計を 1 回読んで計算する。両者の差は呼び出し間の数マイクロ秒。
- `linuxBus` は転送を mutex で直列化する。
- 起動時に `Run` へ渡した `ctx` が既に取り消されていても、最初の `Tick` は 1 回実行する。
- 連続失敗が 5 回に達するとバスを開き直す（`reinits`）。ログは 1 回目と 5 の倍数回のみ。
- 非ループバックで待ち受け、かつ `API_TOKEN` が無いときは、起動時に警告を出す。
- 引数は `--version` だけを受け付け、それ以外は終了コード 2 で拒否する。設定は環境変数と、任意の JSON 設定ファイル（`CONFIG_FILE`）。
- SCD4x は、コマンド送信と応答読み出しを別トランザクションにする。リピーテッドスタートの `WriteRead` では、実行時間（1 ms）を待てない。
- SCD4x の `Init` は、最初に必ず `stop_periodic_measurement` を送り 500 ms 待つ。サービスだけを再起動したとき、センサーは周期測定中のままで、停止するまで他のコマンドを NACK するため。
- SCD4x の `Init` は、シリアル番号の CRC 検証までで、センサーバリアントは確認しない。
- SCD4x の `read_measurement` は、温度・湿度のワードも含めて 3 ワードすべての CRC を検証する。
- SCD4x は 40000 ppm を超える値をエラーにする。
- SCD4x のポーリングは 250 ms 間隔で最大 24 回（約 6 秒）。周期測定は 5 秒周期なので、`INTERVAL=5s` でも位相差を吸収できる。
- SCD4x の失敗は、ENS160・AHT21 の読み出しが成功していてもサンプル全体の失敗にする。部分保存すると、センサーが死んでいても `/healthz` が `200` のままになる。
- `co2_ppm` は、SCD4x が無効な行では出さない（`null` にしない）。無効時の応答を従来と同一に保つため。値が 0 の行は出す。
- CRC-8（多項式 `0x31`、初期値 `0xFF`）は `internal/crc8` に置く。AHT21・SCD4x・I2C シミュレーターで共有する。
- 設定ファイルの値は、対応する環境変数名の `map` に写像してから、環境変数と同じ検証コードを通す。検証を二重に持たないため。副作用として、ファイル由来の値のエラーも環境変数名で報告される。
- 環境変数の値が非空なら、ファイルの値より優先する。空の環境変数でファイルの値は打ち消せない（空文字列は未設定と同じという既存の規則を保つ）。
- 設定ファイルは `DisallowUnknownFields` で読み、JSON の後ろの余分な内容と 64 KiB 超を拒否する。打ち間違いで設定が黙って無視されるのを避けるため。
- `API_TOKEN` は設定ファイルから読まない。秘密情報は 0600 の環境変数ファイルだけに置く。ファイルのパーミッション検査を実装する代わりに、そもそも置けないようにした。
- アドレスの重複検査は、有効なセンサー同士だけで行う。値の範囲検査は、無効なセンサーでも行う（打ち間違いを早く見つけるため）。
- `Session` は `Climate()`・`Gas()`・`CO2()` のアクセサーを持ち、無効なセンサーは `nil` インターフェースを返す（型付き `nil` を返さない）。無効なセンサーのドライバーは生成も初期化もしない。
- ENS160 への補正は、AHT21 が有効なときだけ書く。無効なときに疑似的な値（25 ℃・50 %RH）を書くことはしない。
- ENS160 が無効な行の `valid` は `true`。`valid_only` を、センサー構成によらず同じ意味で使えるようにするため。
- `store.Reading` は、センサーごとに `HasClimate`・`HasGas`・`HasCO2` を持つ。0 が正常値になりうる（0 ℃、0 ppm）ので、値のゼロ判定では有無を区別できない。API では、これらを `nil` ポインターと `omitempty` に写像する。
- 温湿度の供給源は、AHT21 が有効なら AHT21、無効で SCD4x が有効なら SCD4x。暗黙に選ぶ（設定項目にしない）。AHT21 と SCD4x の両方があるとき、SCD4x の温湿度は捨てる。
- SCD4x の 1 回の測定結果（CO2・温度・湿度）は 1 回しか読めない。`scdSource` は `Measure` で読んだ結果を 1 サンプルだけ保持し、直後の `ReadCO2` で消費する。`Measure` を経由しない `ReadCO2`（AHT21 が温湿度の供給源のとき）は、自分で読む。`Measure` は呼ぶたびに保持分を破棄して読み直すので、途中のステップが失敗した次の周期に、古い CO2 を使い回すことはない。
- SCD4x の温度オフセット（`set_temperature_offset`）は書き込まない。センサーの状態を変えず、補正は既存の `TEMP_OFFSET` に一本化する。代償として、湿度は温度の補正に追従しない。
